## Overview

This project is a customization of the **FoodMart** Bootstrap-based HTML template designed for an online food marketplace. The original clean and modern design is enhanced by adding core user authentication features:

- **User Registration**
- **User Login**
- **User Logout**

All authentication data is stored securely in the browser's **localStorage** for simplicity and demo purposes.

The project uses plain **JavaScript, HTML, and CSS** to extend the original static template into a more interactive user experience without backend dependencies.

---

## Features

- Responsive, modern Bootstrap-based UI for an online food marketplace
- Custom login, logout, and registration functionality built with vanilla JS
- User data saved and retrieved from localStorage
- Form validation for authentication forms
- User session management with login state persistence
- Simple and clear codebase for easy customization and extension

---

## Technologies Used

- HTML5
- CSS3 (Bootstrap 5)
- JavaScript (Vanilla JS, ES6+)
- localStorage API for client-side data persistence

---

## Customization
Modify the Bootstrap styles or add your own custom CSS under /css/custom.css.

Extend or adjust authentication logic in /js/auth.js.

Add backend integration in the future by replacing localStorage with API calls.

Enhance security by implementing password hashing and server-side authentication if needed.
